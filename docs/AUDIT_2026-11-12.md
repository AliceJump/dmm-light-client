## 原始问题的处理

学园偶像大师的界面曾根据状态文案是否含“未安装”推断安装成功，导致“未识别官方安装记录”也显示“已安装”。详情页又把更新送入通用安装接口，而该游戏需要专用更新流程。失效的专用安装记录还会阻止后续有效来源参与检测。

PR #3 已统一安装状态判定：依次验证专用记录、旧通用记录、官方记录，并检查目录与 `gakumas.exe`。失效目录不计入已安装；中断更新日志使用独立的恢复状态。车库、详情、原生界面、Web 界面和 CLI 使用同一套专用检查、更新和启动路由，目录重新绑定也会刷新当前详情。

这项修复不会凭空恢复已经不存在的游戏文件。学园的专用安装器首次安装仍是明确标示的功能限制；已有游戏目录的绑定、更新、恢复和启动是本次修复覆盖的能力。

### 网络、代理与账号

| 编号 | 优先级 | 触发条件与影响 | 修复方式 |
|---|---|---|---|
| N01 | P1 | 节点进程能启动、但所有出口请求失败时，节点轮转和请求层循环可能永远重试。 | 每次请求限制尝试次数，失败后停止并保留断点；后续用户操作可以重新尝试。 |
| N02 | P2 | 后台封面或版本请求复用代理池时，覆盖前台操作的取消与进度回调。 | 回调绑定每个操作的代理地址及 HTTP adapter，共享节点进程但不共享操作的取消状态。 |
| N03 | P2 | 配置替换或关闭后，旧 HTTP 会话可通过旧 pool 的失败重试重新启动未受 Hub 管理的 Xray。 | 将当前节点关闭与整个 pool 永久退役区分；退役 pool 拒绝重新启动和继续请求。 |
| N04 | P2 | Xray 下载先读取完整响应再检查大小，版本信息和校验文本也没有接收上限。 | 流式读取时执行限额和取消检查，超限立即停止接收并关闭响应；保留官方发布来源与 SHA-256 校验。 |
| N05 | P1 | 会话先读活动账号编号、再读当前登录文件，切换期间可得到不同账号的组合；刷新写入与账号切换的检查、落盘过程不完整串行。 | 从同一账号快照取得固定文件路径；账号检查和写入使用短时共享锁，同线程已有操作锁可重入，避免后台或 CLI 切换时覆盖当前会话镜像。 |
| N06 | P2 | 登录候选构造在 `try/finally` 之前失败时，候选加密快照可能留在临时目录。 | 将候选构造纳入清理范围，只清理本流程创建的已知文件。 |
| N07 | P2 | 非法 URL 端口、异常 JSON 结构和不严格的登录成功回调可落入原始异常路径。 | 统一地址与响应形状校验，登录回调要求正确 HTTPS 主机、端口、路径及唯一非空 code，错误不回显敏感请求内容。 |
| N08 | P2 | 节点保存、删除和后台记录最近成功节点可能互相覆盖；旧池继续使用已修改的节点，旧请求还可能把已删除节点写为首选项。 | 节点修改使用共享锁，首选项只记录仍启用的节点，显式配置变更退役对应的旧池；偏好保存失败不改变已成功请求的结果。商店显式操作重新获取当前代理池，避免复用已退役的地址对象。 |
| N09 | P1 | 原生商店页的内嵌 OAuth 登录直接向当前会话换取 token，绕过其他登录入口的候选会话身份校验；浏览器中的其他账号可能覆盖当前存档。 | 内嵌登录同样先写临时会话、验证原账号身份，再采纳到当前存档；失败或取消清理本次临时状态。 |

主要实现：[session.py](../dmmclient/backend/session.py)、[accounts.py](../dmmclient/backend/accounts.py)、[launcher.py](../dmmclient/backend/launcher.py)、[xray.py](../dmmclient/backend/xray.py)。[browser_proxy.py](../dmmclient/backend/browser_proxy.py) 的所有权记录、PAC 恢复和外部修改保护也已复核，现有保护与回归保留。

| U07 | P2 | 后台校验旧目录期间发生迁移或卸载，旧结果会写到新记录并刷新 UI。 | 最终写入前取得共享锁并核对捕获的产品根目录；两套界面拒绝旧根目录结果。 |

## 复核边界

本次没有用真实账号执行登录、购买、游戏下载或游戏启动，也没有在用户电脑上触发 UAC、重装游戏、清理文件、修改系统代理或替换已安装客户端。网络、权限、进程及故障注入场景采用明确 mock；Windows 原生参数解析和跨进程文件锁由 Windows 测试覆盖。打包资源检查也不等于真实游戏的端到端验收。

服务器未提供摘要的文件仍只能按协议校验大小；重新获取缓存不能补出服务器没有提供的内容摘要。文件路径检查没有使用 Windows 目录句柄将整条路径固定，因此不声称消除另一个恶意本地进程同时置换路径的所有竞争窗口。迁移若在完整新副本发布后遇到安装记录写入失败，会同时保留旧源和完整新副本，避免损失文件；这种失败需要后续处理重复副本。

网络重试预算按层限制：节点 adapter 的单次请求和响应体中断后的外层重试各有上限，极端情况下总次数可能为两个上限的乘积。所有循环保留取消检查，因此不再无限轮转，但没有将所有传输层合并为一个总尝试计数。

原生回退界面的内嵌商店 OAuth 仍使用同步 HTTP，慢网时该页可能等待请求超时；常规 Web 界面的登录走后台 Worker。关闭保护会在等待预算耗尽后保留窗口并提示再次关闭，不会强杀尚未结束的线程。

已确认的本地代码问题随审计修复提交；专用安装器首次安装、付费游戏、订阅和额外 DRM 等原有能力边界继续在使用文档中说明。审计覆盖上述代码修订与本次测试场景，不声称穷尽所有未来输入、网络服务变化或本机外部进程的竞争行为。
