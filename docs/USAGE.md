# DMM Light 客户端 使用指南

面向使用者的操作说明。本文只讲"怎么用"，不含任何内部实现细节。

- 适用平台：Windows 10 / 11（64 位）
- 使用前提：一个可正常登录的 DMM 账号；DMM 只对日本 IP 提供服务，需要能连到日本的网络出口

---

## 1. 安装与启动

### 方式一：用发布包（推荐）

1. 到本仓库的 **Releases** 页面下载最新版 `DmmLightClient-<版本>-win64.zip`。
2. 解压到任意目录（**不要**放进 `Program Files` 这类需要管理员权限的目录）。
3. 双击解压出来的 `DmmLightClient.exe`。

首次启动会在 `%LOCALAPPDATA%\DmmLightClient` 下建立数据目录，用于存放登录态、账号快照、游戏目录缓存、封面图缓存等。

### 方式二：从源码运行（开发/自用）

需要先装好 Python 3.12+ 与 [uv](https://docs.astral.sh/uv/)：

```bat
uv sync
start.cmd
```

`start.cmd` 会自动激活虚拟环境并启动图形界面。命令行入口见第 9 节。

---

## 2. 首次使用：登录

1. 打开左侧栏的 **账号** 页，点「登录」。
2. 客户端内置的浏览器会打开 DMM 官方登录页，按官方流程输入账号、密码、验证码。
   - 密码与验证码始终在 DMM 官方网页输入，客户端不接触、不保存你的密码。
   - 若开了两步验证，按官方提示完成即可。
3. 登录成功后，客户端会自动用你的 DMM GAMES ID 与昵称建立一条账号记录，无需手动填写。
4. 账号页顶部会显示当前登录的是谁；未登录时会明确提示。

> 登录态失效（例如长时间未使用）时会提示重新登录，重新走一次上面的流程即可。

---

## 3. 网络与节点

DMM 拒绝日本以外的 IP，直连通常打不开。客户端提供两种方式：

- **内置节点池（推荐）**：在 **网络** 页导入节点，客户端会自动轮换并在节点故障时切换。侧边栏底部会显示当前可用节点数。
- **外部代理**：在网络页填入 HTTP 或 SOCKS5 代理地址，并点「测试连接」验证是否可用。

说明：

- **登录**用内置浏览器，需要 HTTP 代理或内置节点；SOCKS5 用于接口请求与游戏下载。
- 系统浏览器打不开 DMM 通常是因为本机出口不在日本，这不是客户端的问题——用内置节点或日本出口的代理即可。

---

## 4. 安装、更新与启动游戏

1. 首次使用先到 **发现** 页点「刷新」，拉取游戏目录（同时覆盖一般游戏与 FANZA / R18 游戏）。
2. 发现页支持按 **一般 / FANZA / 已安装** 筛选，也可以直接搜索。
3. 点卡片上的按钮即可：

   | 按钮 | 作用 |
   |---|---|
   | 安装 | 全新安装到所选目录 |
   | 更新 | 更新到最新版（支持断点续传） |
   | 启动 | 启动游戏（启动前会自动检查并更新） |
   | 详情 | 打开游戏详情页（见第 5 节） |
   | 目录 | 查看/修改该游戏的安装位置 |
   | 卸载 | 卸载（见第 7 节） |

4. 第一次全新安装会弹一次目录选择（默认 `<数据目录>\games`），选过之后会记住；实际安装位置是 `<所选基准目录>\<游戏编号>`。
5. 部分游戏需要先装系统运行库（VC++ 运行库 / DirectX），客户端会像官方一样自动下载并以管理员身份运行，**可能弹出 UAC 授权框**，请允许。已装过同一版本的会自动跳过。

> 首次安装与首次启动都不需要预先装官方 Player。
> 游戏首次运行可能还要自行下载额外资源，"启动到标题画面"不等于游戏内登录完成。

---

## 5. 游戏详情页

- 点卡片或发现页的「详情」进入。左侧是全部游戏的紧凑列表（已装/未装都能切换），右侧是详情。
- 详情包含简介、截图、宣传片、厂商/类型/对应系统、运行环境要求、注意事项与官方链接。
- 内容由客户端原生渲染，**不加载官方网页，也不需要官方 Player**。
- 普通版与 R18 版之间可以一键互跳。
- 详情与截图会缓存，第二次打开是即时的；拿不到时只显示本地目录与安装信息，不会报错或卡住。

---

## 6. 账号管理

- 登录成功后会自动建立账号记录，不需要手动建档。
- 想保留多份登录态：在账号页填写 **编号** 与 **名称**，再点「保存当前账号」。
- 同一编号重复保存即为**改名**。
- 可以在账号页直接切换账号。
- 游戏运行中也能切换账号，但**已启动的游戏仍持原有会话**，需重启游戏才生效。

---

## 7. 安装目录与卸载

### 修改安装位置

- 卡片上的「目录」按钮：未安装时用来**预设**安装位置；已安装时是把游戏**整体搬迁**过去。
- 搬迁支持跨盘，带进度，先完整复制再删源目录；中途失败源目录仍然完好。
- 也可用命令行：`dmmcli dir` 查看/修改，`dmmcli move` 搬迁。

### 卸载

- 卡片上的「卸载」会先弹确认框，**默认是「只移除记录，保留文件」**；要删文件需单独点「彻底删除」。
- 删除只针对记录里的那一个目录，且会挡掉盘符根目录、用户主目录、数据目录这类不安全目标。
- 游戏运行中拒绝卸载。
- 命令行：`dmmcli uninstall <游戏>` 不加 `--yes` 只预览不删；`--keep` 只移除记录保留文件。

---

## 8. 界面与操作

- 界面**跟随系统明暗**：系统切浅色就浅色、切深色就深色，运行中切换也会立刻换肤。
- 左侧是常驻侧边栏（车库 / 发现 / 账号 / 网络），顶部是页面标题栏，底部状态栏放进度、状态、暂停与可折叠日志。
- 车库页顶部有「继续游戏」大图（上次启动的游戏），下面是卡片墙。
- 卡片用 1:1 方形封面，角标显示已安装 / 可更新 / R18。
- 触摸屏可用：卡片墙、日志与账号/网络页都支持手指拖拽滚动（带惯性）。
- 操作互不阻塞：某个操作进行中再点别的会**排进队列**，当前操作结束后自动接着执行。

## 9. 命令行 `dmmcli`

图形界面之外还有一套命令行，复用同一份数据、登录态和节点配置，不需要图形界面：

```bat
dmmcli list                             已安装的游戏（编号 / 版本 / 目录 / 来源）
dmmcli list --json                      同上，JSON 输出
dmmcli catalog -q ウマ娘                 在本地缓存的目录里搜索
dmmcli catalog --filter adult            只看 FANZA R18
dmmcli refresh                           联网刷新游戏目录
dmmcli check umamusume                   只查版本，不下载
dmmcli install umamusume                 全新安装（默认装到 <数据目录>\games\umamusume）
dmmcli install umamusume --dir D:\GAMES\DMM   指定基准目录，实际装到 D:\GAMES\DMM\umamusume
dmmcli update umamusume                  更新到最新版
dmmcli launch umamusume                  启动（启动前自动检查并更新）
dmmcli dir umamusume                     看当前目录与安装位置
dmmcli dir umamusume --set E:\Games      改安装位置
dmmcli move umamusume --dir E:\Games     把已装好的游戏搬过去
dmmcli uninstall umamusume               预览要删什么（不加 --yes 不真删）
dmmcli uninstall umamusume --keep        只移除安装记录，保留文件
dmmcli accounts                          列出账号；--switch 12345 切换
dmmcli nodes                             列出已导入节点
dmmcli proxy                             查看代理；dmmcli proxy http://127.0.0.1:10808 修改
dmmcli ping                              测试连接与登录态
```

安装后 `dmmcli` 命令即可用；项目根目录也放了 `dmmcli.cmd` 包装（免激活虚拟环境），也可以直接用 `python -m dmmclient.cli`。

> 命令行**不会弹浏览器**。登录态失效时会提示你先在图形界面登录一次。

## 10. 数据存放位置

| 内容 | 位置 |
|---|---|
| 数据目录（登录态、账号快照、设置） | `%LOCALAPPDATA%\DmmLightClient` |
| 游戏默认安装位置 | `<数据目录>\games\<游戏编号>` |
| 游戏安装记录 | 数据目录下的 `games.json` |
| 目录 / 封面 / 详情缓存 | 数据目录下相应子目录 |

客户端使用自己的数据目录，**不会修改官方 Player 的账号或配置文件**。

## 11. 常见问题

**打不开 DMM / 一直转圈**
本机出口不在日本。到网络页导入内置节点，或填入日本出口的 HTTP/SOCKS5 代理后重试。

**登录页加载不出来**
登录走内置浏览器，需要 HTTP 代理或内置节点；确认网络页里选的是 HTTP 代理或节点池。

**启动游戏弹 UAC**
部分游戏需要 VC++ 运行库 / DirectX，客户端以管理员身份安装这些模块，允许即可；同一版本只会装一次。

**版本号显示不对**
启动后与每次操作结束，客户端都会后台核对已安装游戏的清单。用官方启动器或第三方工具更新过也能自动纠正；点「检查」同样会顺手纠正记录。

**提示暂不支持**
需要专用安装程序或 DRM 授权的游戏暂不支持；付费游戏、订阅刷新、商店与付费操作也尚未实现。

**想彻底清干净**
退出客户端后删除 `%LOCALAPPDATA%\DmmLightClient` 即可（会同时清掉登录态、账号快照与缓存）。

---

## 12. 已知限制

- 仅支持 Windows，仅支持标准下载型游戏（GCL / ACL）。
- 未实现：付费游戏、订阅刷新、商店与付费操作。
- 未提供单文件安装包，发布形态为解压即用的 zip。
- 游戏运行后的网络由游戏自身处理；客户端的代理只负责登录、清单、更新与下载。
