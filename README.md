# DMM Light 独立客户端预览版

独立 Windows 桌面程序，不加载 ok-script，不关联自动化任务。使用自己的虚拟环境和 `%LOCALAPPDATA%\DmmLightClient` 数据目录。

运行：双击 `start.cmd`。新机器先安装 Python 3.12+ 和 uv，再运行 `uv sync`。

界面按游戏管理中心规划，左侧导航四个页面：**我的车库**（已装游戏卡片墙：封面、版本、启动/检查/更新直接在卡片上）、**发现游戏**（可搜索、可按一般/Fanza/已安装筛选的封面卡片网格，卡片上一键全新安装）、**账号**、**网络**。封面图后台自动预取并缓存，无需等待。

已实现：已安装学园偶像大师的版本检查、启动前自动更新、下载进度、暂停与断点续传、文件校验和更新恢复；浏览器登录、加密账号快照与切换；内置 Xray 多节点轮换及故障切换；HTTP / SOCKS5 外部代理设置和连接测试。封面图从官方详情页抓取并缓存，目录同时覆盖一般游戏与 Fanza（R18）游戏。

密码与验证码由用户在 DMM 官方网页输入。默认浏览器登录临时使用所选 HTTP 代理，完成或取消后恢复。SOCKS5 用于 API 和下载；浏览器登录请使用 HTTP 或内置节点池。

游戏目录可以手动选择，第一次也可只读识别官方 Player 安装记录。保存本客户端的安装记录后，后续不需要官方 Player 安装配置。不会修改官方 Player 的账号或配置文件。

支持已安装的学园偶像大师；其他免费下载型游戏可先「刷新游戏列表」再选择，直接全新安装、检查更新和启动，无需预先下载过。目录同时覆盖一般版与 Fanza 版（标记 R18），一次刷新全部拿到：Fanza 游戏走 `ACL` 类型与 `app-gameplayer.dmm.co.jp` 域名，需要已完成年龄认证的 DMM 账号（客户端通过 `age_check_done` cookie 声明）。未加库的游戏安装时自动调用官方加库接口加入游戏库；**首次安装与首次启动都不需要官方 Player**——DMM 对「尚未同意该游戏利用规约」的账号会拒绝 `install` 与 `launch` 接口（`result_code=308`，官方错误码表为 `NOT_CONSENT_AGREEMENT`），客户端在你主动点安装/启动时自动代为提交该游戏的利用规约同意（`/v5/agreement/confirm/client`），随后正常安装与启动；若 `install` 仍被拒，再退回下载清单接口 `/v5/r2/filelist/cl` 直接取得文件清单与 CloudFront 签名 cookie（与官方 `cex.dll` 下载时同源）。下载一律从 CDN 直连并逐文件 MD5 校验，支持断点续传。新游戏安装在本客户端数据目录的 `games/<游戏编号>` 中，安装记录写入独立 `games.json`，不会写入官方 Player。仅支持标准下载型游戏（GCL/ACL）；需要专用安装程序、额外运行模块或 DRM 授权的游戏会明确提示暂不支持。

实测公主连结 12.7.2 下载约 248 MiB，29 个文件全部校验通过，未经过官方 Player 即启动到标题画面。游戏首次运行还可能需要自行下载额外资源；标题画面不等于游戏内登录完成。

尚未实现付费游戏、卸载、订阅刷新、商店与付费操作，也未制作单文件安装包。额外安装程序、模块和 DRM 流程暂不支持。游戏运行后的网络由游戏自身处理，本客户端代理负责登录、清单、更新和下载。

开发验证：`.venv\Scripts\python.exe -m unittest discover -s tests`。
